# DEMO Summary

## Что уже работает

- Локальный MVP собирает материалы из федеральных, региональных и отраслевых источников по АПК.
- Поддержан сбор HTML, PDF и DOCX; для сканов архитектурно предусмотрен OCR, пока как заглушка.
- Документы сохраняются в SQLite, дубли по URL и контенту отсекаются.
- Реализован rule-based анализ релевантности для GR:
  - `requires_attention`
  - `watchlist`
  - `background`
  - `irrelevant`
- Реализована дополнительная классификация `page_type`, которая помогает отсеивать служебные, архивные и реестровые страницы.
- Формируется ежедневный markdown-отчет с короткой сводкой и ссылками на источники.
- Для demo ежедневный отчет уже очищен от большей части навигационного и служебного шума.

## Пример текущего результата

По итогам текущего demo-прогона:

- в базе: `126` релевантных документов за выбранную выборку;
- в ежедневном отчете:
  - `3` пункта в разделе `Требует внимания GR`
  - `5` пункта в разделе `На наблюдении`
- скрыто служебных/реестровых/архивных страниц: `118`

Примеры `Требует внимания GR`:

- Компенсация затрат на создание и модернизацию объектов АПК
- Возмещение части затрат на поддержку сельскохозяйственного производства, животноводства
- Льготное кредитование АПК

Примеры `На наблюдении`:

- Льготный лизинг высокотехнологичного оборудования и техники (АПК)
- Гарантия ВЭБ.РФ
- Господдержка. Транспортировка товаров АПК

## Ограничения MVP

- Анализ пока rule-based, без реального LLM.
- OCR для сканов пока не реализован.
- Не все источники стабильно доступны: часть сайтов отдает `403`, SSL-ошибки или `502`.
- Часть сайтов пока разбирается generic-логикой, без полноценных source-specific parser-ов.
- `published_at`, дедлайны, суммы субсидий, номера НПА и даты вступления в силу пока не извлекаются как структурированные поля.
- Карточки мер поддержки и новости уже очищаются заметно лучше, но качество still зависит от структуры конкретного сайта.

## План следующих этапов

### Этап 1. Повышение качества анализа

- Подключить реальный LLM для summary и оценки релевантности.
- Выделять структурированные поля:
  - дедлайн
  - дата вступления в силу
  - тип меры поддержки
  - регион
  - сумма/вид субсидии

### Этап 2. Повышение качества сбора

- Добавить source-specific parser-ы для:
  - `mcx.donland.ru`
  - `msh.krasnodar.ru`
  - `admkrai.krasnodar.ru`
  - `gisp.gov.ru`
- Реализовать OCR для PDF-сканов.

### Этап 3. Операционный контур

- Ежедневный scheduler
- file logging
- уведомления в Telegram/email
- накопление архива и поиск по документам
